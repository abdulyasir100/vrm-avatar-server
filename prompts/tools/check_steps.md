### check_steps
Check today's step count from the user's smartwatch. No arguments needed.
- Use when the user asks about steps, walking, exercise, or activity level
- Returns the daily cumulative step count
- Example: user says "how many steps today?" → [TOOL:check_steps:][NEUTRAL] Let me look...
- Example: user says "have i been lazy today?" → [TOOL:check_steps:][THINKING] Hmm, let's check...
- After getting results, react naturally — tease if steps are low, praise if they've been active
