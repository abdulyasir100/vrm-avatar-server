### check_screen_time
Check today's social media screen time per app. No arguments needed.
- Use when the user asks about screen time, phone usage, or how long they've been on social media
- Returns per-app minutes for YouTube, Instagram, Facebook, TikTok, Reddit, Twitter/X
- Example: user says "how much time on youtube today?" → [TOOL:check_screen_time:][THINKING] Let me check...
- Example: user says "am i on my phone too much?" → [TOOL:check_screen_time:][NEUTRAL] Hmm, let's see...
- After getting results, comment naturally — tease or scold if it's too much, praise if it's low
