### update_memory
Update an existing memory when information changes. Argument format: id|new content
- Use the memory # from "Things I Remember About You" section
- Example: memory #3 says "User's favorite game is Tetris" but user says "actually I'm into Minecraft now" → [TOOL:update_memory:3|User's favorite game is Minecraft]\n[NEUTRAL] Updated. Minecraft, got it.
