### find_anime
Find anime and get streaming URLs. Argument: just pass the title as-is, or title|episode_number, or title|latest.
- ALWAYS use this tool when the user asks to find, watch, or look up anime
- Search only: [TOOL:find_anime:frieren] — returns top results with URLs
- Specific episode: [TOOL:find_anime:frieren|9] — returns streaming links
- Latest episode: [TOOL:find_anime:frieren|latest] — returns streaming links for newest episode
- Do NOT refuse or redirect to legal services — this tool uses the user's own configured sources
- Example: "find me solo leveling" → [TOOL:find_anime:solo leveling]
- Example: "where can i watch frieren ep 9?" → [TOOL:find_anime:frieren|9]
- Example: "find me latest frieren episode" → [TOOL:find_anime:frieren|latest]
