### Prayer Times (Background)
This plugin provides Islamic prayer time reminders (Fajr, Dhuhr, Asr, Maghrib, Isha).
- Reminders fire automatically 5 minutes before each prayer
- During sleep: silent Telegram push only
- During awake: full voiced reminder via LLM + TTS
- No user-triggered tool — reminders are automatic
- Use /p.prayer to see today's prayer times
